StellarForge: A Gamified, AI-Assisted Task Management System for University Students with ADHD

Uswa Masood Department of Computer Science Air University Islamabad, Pakistan uswamasood02@gmail.com

Abstract—Students with attention-deficit/hyperactivity disorder often struggle to start and finish academic tasks that look large and unstructured. This paper presents StellarForge, a full-stack web application that turns everyday tasks into gamified missions and uses a machine learning component to split each task into three to seven small, actionable steps in under one second. The system follows a three-tier architecture built on Blazor WebAssembly, ASP.NET Core, and MongoDB, with Fluxor for predictable client state and Firebase authentication combined with JSON Web Tokens for secure access. Progress is rewarded through an experience-point model that gives immediate feedback for each completed step. We describe the design goals, architecture, task decomposition service, and gamification model, and we outline a plan for evaluating the system with student users.

Keywords—gamification, ADHD, task decomposition, student productivity, Blazor WebAssembly, ML.NET

Introduction

Attention-deficit/hyperactivity disorder (ADHD) is a neurodevelopmental condition characterized by persistent patterns of inattention and hyperactivity-impulsivity [1]. University life is demanding for students with ADHD because it depends on skills that the condition tends to affect, such as planning, sustained attention, and self-regulation [2]. A single assignment such as "write the project report" gives no clear starting point, and this ambiguity often leads to delay.

Most task management tools store tasks but do not help students begin them. StellarForge addresses this gap in two ways. First, it breaks each task into a short sequence of concrete steps. Second, it presents those steps as missions with visible progress and rewards, so that each small action produces immediate feedback.

The contributions of this paper are: (1) a three-tier web architecture for a gamified task manager, (2) a task decomposition service built on ML.NET that returns three to seven steps per task, and (3) an experience-point progression model designed around short feedback loops. The rest of the paper is organized as follows. Section II reviews related work, Section III describes the system design, Sections IV and V present the decomposition service and the gamification model, Section VI summarizes the implementation, and Section VII concludes.

Related Work

Gamification is commonly defined as the use of game design elements in non-game contexts [3]. A review of empirical studies found that gamification usually produces positive effects, although the results depend strongly on the context and on the users [4]. Self-determination theory explains part of this effect: activities that support feelings of competence and autonomy sustain intrinsic motivation [5]. StellarForge applies this idea by making progress visible and by letting the student choose which mission to start.

For ADHD, a widely cited theory links the condition to weak behavioral inhibition, which in turn affects sustained attention and executive functions [2]. This motivates external structure, such as small steps and immediate feedback, as a form of support. On the technical side, ML.NET provides a framework for adding machine learning to .NET applications without leaving the .NET ecosystem [6], which fits the technology stack chosen for this project.

System Design

Design Goals

Three goals guided the design. The first is low friction: the student should be able to add a task and see actionable steps within seconds. The second is clear feedback: every completed step should be acknowledged visibly. The third is maintainability: the client, server, and data layers should be separable so that each can change independently.

Three-Tier Architecture

StellarForge uses a three-tier architecture, shown in Fig. 1. The presentation tier is a Blazor WebAssembly client [7] that runs in the browser. The application tier is an ASP.NET Core web API that hosts the business logic and the ML.NET decomposition service. The data tier is a MongoDB database that persists users, tasks, steps, and progress. Each tier communicates only with its neighbor, which keeps responsibilities separate.

State Management and Authentication

The client keeps its state in a Fluxor store [8], which follows the unidirectional data flow pattern. Every change, such as completing a step or gaining experience points, is expressed as an action handled by a reducer, so the interface always reflects a single source of truth. Users sign in through Firebase OAuth [9]. After sign-in, the client sends a JSON Web Token [10] with each request, and the API validates it before touching any data.

Intelligent Task Decomposition

The decomposition service is the feature that most directly targets task initiation. It accepts a free-text task title and returns an ordered list of three to seven steps. The lower bound prevents trivial output, and the upper bound prevents a long list that would itself become overwhelming. The service is implemented with ML.NET and exposed through the API tier, so the client requires no machine learning code.

Response time matters for this audience. A student who waits several seconds may lose the impulse to begin, so the service is designed to respond in under one second. The steps are then stored with the task, and each one becomes an individual item that the student can complete and be rewarded for.

Gamification Model

Missions

Each task becomes a mission, and its steps become objectives inside that mission. The interface uses a space theme with a dynamic layout that updates as objectives are completed. The theme is not only decorative: it gives the student a consistent story in which small actions move the mission forward.

Experience Points

Students earn experience points (XP) for completing steps and missions, and accumulated XP drives a progression system. Rewards are granted at the moment of completion rather than at the end of a long task, which keeps the feedback loop short. This design choice reflects the finding that immediate, competence-supporting feedback helps sustain motivation [5].

The evaluation so far is technical. We have not yet run a formal study with students who have ADHD, so this paper makes no claim about improved focus or task completion. We plan to compare StellarForge with a conventional to-do list, measuring task start time, completion rate, and self-reported usability.

Conclusion and Future Work

This paper presented StellarForge, a gamified task manager that combines automatic task decomposition, immediate XP rewards, and a three-tier architecture built on Blazor WebAssembly, ASP.NET Core, and MongoDB. The system is designed to reduce the effort of starting tasks for students with ADHD. Future work includes the user study described above, adaptive step sizes based on how each student performs, and accessibility options such as reduced motion and adjustable reward frequency.
